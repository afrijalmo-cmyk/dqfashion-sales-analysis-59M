# DQFashion Sales Analysis 2017 | 59.9 Miliar IDR Dashboard

End-to-end sales analysis & performance dashboard using Excel & DAX - 59.9 Billion IDR

## 📌 Ringkasan Proyek
Menganalisis penurunan revenue Semester II 2017. Dataset: 236.746 produk, 396 transaksi, 4 cabang (Jakarta, Makassar, Medan, Surabaya).

**Tools:** Excel, Power Pivot, DAX (SUMX, RELATED, DIVIDE)

## 🔍 Proses Saya (BNSP Standard)
1.  **Data Cleaning:** Cek tipe data, format tidak seragam, duplikat, kode transaksi, Trim spasi berlebih
2.  **Data Modeling:** Relasi Transaksi Penjualan + Master Produk + Master Cabang + Kalender Libur
3.  **DAX Measures:** Product Sold, Total Revenue, Revenue/TRX

## 📊 Hasil Dashboard
- **Total Revenue:** Rp 59.96 Miliar
- **Product Sold:** 236.746 unit
- **Revenue/Trx:** Rp 151.4 Juta
- **Bulan Tertinggi:** Juni 7.94 M (+64% karena Idul Fitri)

## 💡 Insight Utama
- Idul Fitri 618 Jt = 3.8x lebih besar dari libur lain
- Gap cabang hanya 4.6% (sangat sehat) - Medan 26%, Surabaya 24%
- Top Product: Jaket 7.6 M - rekomendasikan bundling + stok 2x menjelang Lebaran
